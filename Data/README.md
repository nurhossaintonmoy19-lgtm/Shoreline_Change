# Data

This directory contains the datasets used for shoreline change analysis in the Meghna Estuary.

## Data Sources

- Sentinel-2 satellite imagery
- Study area boundary
- Extracted shoreline datasets

## Data Organization

- `Satellite_Images/` – Satellite imagery for selected years.
- `Study_Area/` – Study area boundary files.
- `Shoreline_Data/` – Extracted shoreline datasets.

Raw satellite imagery may be stored locally or accessed through external data repositories due to file size limitations.
