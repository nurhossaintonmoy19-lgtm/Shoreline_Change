# Satellite Images

Satellite imagery used in this project will be collected from the Copernicus Data Space Ecosystem.

## Satellite Data

- Satellite: Sentinel-2
- Product: Level-2A
- Spatial Resolution: 10 m (selected bands)
- Study Period: 2015, 2020, 2025

## Purpose

These satellite images will be used to extract shorelines and analyze shoreline changes over time.
