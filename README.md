
# Shoreline Change Analysis of Meghna Estuary, Bangladesh

## 1. Project Overview
This project analyzes shoreline changes along the Meghna Estuary
in Bangladesh using satellite imagery and GIS techniques.

## 2. Objective
- Extract shoreline from satellite imagery.
- Analyze shoreline changes over time.
- Identify erosion and accretion zones.

## 3. Study Area
The study area is the Meghna Estuary, Bangladesh.

## 4. Data Sources
- Landsat satellite imagery, sentinel satellite imagery
- Google Earth Engine
- Geographic boundary data

## 5. Methodology
- Satellite image selection
- Image preprocessing
- Water index calculation
- Shoreline extraction
- Shoreline comparison
- Erosion and accretion analysis

## 6. Results
Maps and analytical results are presented here.

## 7. Limitations
- Satellite image resolution
- Tidal variation
- Seasonal variation
- Water index threshold sensitivity

## 8. Tools
- Google Earth Engine
- QGIS
- Python
